# AWS IAM User, Group & Policy Management

## Overview

This project demonstrates hands-on implementation of AWS Identity and Access Management (IAM) concepts including IAM users, groups, managed policies, inline policies, MFA configuration, and IAM Policy Simulator testing.

---

## AWS Services Used

- AWS IAM
- Amazon S3
- IAM Policy Simulator

---

## Key Features

- IAM user creation
- IAM group management
- Managed policy attachment
- Inline policy creation
- MFA configuration
- Permission simulation and validation

---

## Users Created

- dev-user
- ops-user
- readonly-user

---

## Groups Created

- Developers
- Ops
- ReadOnly

---

## Security Features

- MFA enabled for IAM users
- Custom inline policy for restricted S3 access

---

## Policy Testing

Validated permissions using:
- IAM Policy Simulator

---

## Key Learnings

- Managed vs Inline Policies
- Explicit deny vs implicit deny
- MFA implementation


---

## Outcome

Successfully implemented and tested a secure IAM environment with role-based access control and policy validation using AWS IAM best practices.
